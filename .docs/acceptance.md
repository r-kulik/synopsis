# Приёмка и прослеживаемость требований

Статус всех сценариев: **не выполнено — реализации пока нет**. Таблица задаёт проверки, а не сообщает об уже прошедших тестах.

## Контрольный курс

«Линейная алгебра»: две лекции («Векторы», «Матрицы»), обычные понятия «Вектор», «Матрица», «Диагональная матрица», «Симметричная матрица»; внешнее понятие «Косинус»; пример к двум понятиям; задача к двум понятиям; PDF на несколько страниц; локальное изображение; факт с маркером и факт без привязки; отдельный конспект без карточки. Есть межлекционная контекстная линия с подписью и ручными контрольными точками.

Для тестирования разрешённых циклов добавить искусственный цикл в иерархию как техническую fixture, не выдавая его за корректную классификацию математических объектов. Также создать второй курс с совпадающими названиями для проверки изоляции.

## Уровни проверки

- Domain/contract: изоляция, матрица типов, ID, семантика удаления, привязка фактов.
- Markdown fixtures: корректность source mapping и точечной правки, синтаксис, формулы, malformed URL.
- Integration: транзакционные операции, перезапуск, независимость карты и текста, импорт/экспорт.
- Browser E2E: вкладки, выделение, перемещение/изгибы, видимость, внешнее открытие PDF.
- Ручная визуальная приёмка: читаемость формул и карточек, отсутствие перекрытий нового узла, настройка линий и реальная работа выделения.

Сценарии отказов должны включать ошибку записи, недоступное вложение, старую revision выделения, повреждённый архив, неподдержанную версию и ссылку в другой курс. Тесты не должны быть простым повторением реализации.

## Release gate

Все обязательные AC-01–31 имеют воспроизводимое доказательство выполнения либо согласованное с пользователем изменение требования. AC-32 необязателен. Сборка и статические проверки проходят; нет известных дефектов потери данных, утечки между курсами или повреждения Markdown. Проверены заявленные ОС/браузеры и размер курса, а ограничения опубликованы в руководстве. Нельзя отмечать AC выполненным на основании только заглушки или моков.
