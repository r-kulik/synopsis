# Стартовый промпт S06

```text
Ты исполнитель S06 Synopsis — перенос .synopsis. Прочитай применимые AGENTS.md,
.docs/README.md, functional-requirements.md, domain-model.md, decisions.md,
synopsis-format.md, stages/S06-transfer.md, agents/README.md и ADR S00/S01.
Проверь реальный storage/assets API S02. Работа может идти параллельно UI.

Владеешь transfer/архивными валидаторами и своими fixtures; общую схему,
Markdown URL, map serialization и зависимости меняет интегратор.
Реализуй снимок согласованной сохранённой revision, ZIP/manifest версии по ADR,
включение всех Note/Fact, карточек/рамок/рёбер с точками, стилей/фильтров,
реальных PDF и изображений. Note без карточки и Fact без маркера не теряются.

Импорт проверяет пути, объём распаковки, версии, ID, вложения и отношения;
публикует курс атомарно из staging. Не перезаписывай существующий курс молча.
Невалидные текстовые ссылки после удаления Note допустимы и диагностируются;
структурное повреждение не выдаётся за нормальный импорт.

Внешние картинки/локальные пути должны локализоваться либо явно делать
экспорт неполным по D-13. Не утверждай самодостаточность, если байты недоступны.
Повтори экспорт→импорт в чистое хранилище без доступа к исходным путям.
Сначала fixtures, затем обязательно реальные результаты S04/S05.

Gate: AC-08/11 для переноса, AC-23/28–30. Проверь повреждённый архив,
неподдержанную версию, повторный импорт и изоляцию совпадающих ID.
Не выполняй рекурсивную очистку вне точно выделенной временной области.
Отчёт .docs/reports/S06-report.md: реальные команды, сравнение содержимого,
ошибки, подтверждение чистого окружения и ограничения.
```
