# Стартовый промпт S01

```text
Ты исполнитель доменного этапа S01 Synopsis. Прочитай применимые AGENTS.md,
.docs/README.md, functional-requirements.md, domain-model.md, decisions.md,
markdown-contract.md, synopsis-format.md, stages/S01-contracts.md,
agents/README.md и принятые ADR/отчёт S00. Проверь входной gate S00.

Владеешь общими типами, валидаторами, командами, fixtures и их contract tests
только в путях, назначенных интегратором. Общие зависимости меняются одним
владельцем. Не реализуй полный UI и не запускай дополнительных исполнителей
для конкурентного изменения схемы.

Формализуй Course/Note/Card/LectureBox/Edge/Fact/Source/Asset, независимость
текстовых ссылок и рёбер, контекст курса и стабильные ID. Card может отсутствовать.
Раздели lectureBoxId и при необходимости definedInLectureNoteId. Снятие рамки
сохраняет преамбулу и мировые позиции детей; удаление Note лекции сохраняет
другие конспекты. Внешнее понятие не участвует в hierarchy, циклы обычных
понятий разрешены. Невалидный адрес в Markdown не запрещает сохранить текст.

Определи общий parser/generator synopsis:// URL, revision-aware patch,
согласованное CreateNoteFromSelection и операции фактов. Опиши локальное
сохранение, ошибки, snapshot и версию архива. Закрой нужные D-04–09/12/15
или передай интегратору конкретную неопределённость, не выдумывая новые сущности.

Докажи AC-02/06/07/13/25 на доменных операциях. Укажи реальные команды тестов,
границы API и fixtures для независимой работы редактора, карты и переноса.
Отчёт: .docs/reports/S01-report.md по шаблону. Не объявляй этап завершённым,
если следующий исполнитель вынужден угадывать публичный контракт.
```
