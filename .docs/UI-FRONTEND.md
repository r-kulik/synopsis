# Новый веб-интерфейс Synopsis

Дата: 2026-09-13. Область владельца UI: `frontend/`, кроме `markdown.js` и `vendor/`, которые собирает интегратор.

## Структура

- `frontend/index.html`: настоящая HTML-страница библиотеки курсов, создание и импорт.
- `frontend/course.html`: настоящая HTML-страница рабочего пространства курса.
- `frontend/styles.css`: общая визуальная система, адаптивные раскладки, диалоги, Markdown и состояния интерфейса. Тёплый фон, индиго для главных действий, спокойные оттенки типов карточек, serif-заголовки для чтения.
- `frontend/common.js`: пиктограммы, безопасная HTML-экранизация, HTTP, сообщения, формы и доступные native dialog.
- `frontend/home.js`: список реальных курсов, создание, импорт `.synopsis`.
- `frontend/course.js`: каталог, вкладки, черновики, редактор, создание/изменение/удаление, выделение, факты, PDF, экспорт, разделитель панелей.
- `frontend/map.js`: собственная SVG-карта и взаимодействия через Pointer Events.
- `frontend/bootstrap.js`: независимое отображение ошибок загрузки/исполнения модулей с перезагрузкой страницы.
- `frontend/favicon.svg`: локальный значок приложения.

Нет Python-строк с HTML, inline `onclick`, неявных глобальных переменных по HTML `id`, автоматически созданных учебных данных или внешних CDN-запросов. SVG в главной странице — декоративная иллюстрация, не данные курса.

## Подключение к серверу

Сервер отдаёт `/` → `index.html`, `/courses/:id` → `course.html`, `/static/*` → `frontend/*`. JS — ESM. HTTP-ответ снимка содержит массивы `notes`, `cards`, `lecture_boxes`, `edges`, `facts`, `sources`, `assets`, `lecture_source_attachments` и `course.settings`.

Использованы публичные POST-команды:

- создание/переименование курса, создание всех пяти типов Note, сохранение Markdown по revision, метаданные и удаление Note;
- движение/восстановление/удаление карточек и рамок, размер рамки, принадлежность лекции;
- создание/удаление ребра, подпись, добавление/движение/удаление контрольных точек;
- оформление карточек и рёбер, видимость типов;
- действия выделения `link`, `create-note`, `fact`, `attach-fact`, `source`;
- загрузка вложений и PDF, переименование PDF, прикрепление PDF к лекции;
- сохранение фактов и экспорт `.synopsis`.

PDF открывается отдельной вкладкой: вкладка создаётся синхронно в пользовательском событии, затем адрес проверяется через `GET /api/courses/:cid/sources/:sid/open?page=N`. При блокировке всплывающей вкладки появляется явная ссылка. Номер страницы означает страницу файла PDF.

## Контракт рендерера (владелец — интегратор)

`markdown.js` экспортирует:

```js
renderMarkdown(container, raw, {
  courseId, noteId, snapshot, onNote, onFact, onSource
}); // { diagnostics }
getSourceSelection(container); // { raw_start, raw_end, selected_text }
mountEditor(container, { text, onChange });
// { getValue, focus, destroy, insert }
```

`raw_start` и `raw_end` — позиции UTF-16 исходника. Интерфейс не ищет текст выделения через `indexOf`, а использует привязку рендерера и отправляет revision. Рендерер разрешает безопасное выделение внутри одного текстового AST-фрагмента, включая часть emphasis/strong. Переходы между фрагментами, формулы, код, существующие ссылки и многоблочные диапазоны отклоняются с видимой причиной без изменения текста. Это реальное ограничение текущей операции, а не заявление о полном произвольном выделении.

KaTeX подключён локально через `/static/vendor/katex/katex.min.css`. CodeMirror создаётся только для активной вкладки редактирования и не перестраивается на каждый введённый символ. Ошибка рендера оставляет доступный исходник.

## Вкладки и черновики

У каждой вкладки собственные `text`, `savedText`, `revision`, `mode`. Снимок курса обновляется отдельно, поэтому движение карты, изменения фактов и загрузка вложения не заменяют черновик Markdown. При переключении/закрытии редактор уничтожается, а текст остаётся в состоянии вкладки.

Локальная резервная копия вкладок и черновиков хранится в `localStorage` под ключом с ID курса. Она восстанавливается после перезагрузки. Это не сохранение в `.synopsis`; кнопка «Сохранить» и Ctrl/Cmd+S отправляют явное сохранение по revision. Ошибка не очищает черновик. Закрытие изменённой вкладки предлагает сохранить, отбросить или остаться; уход со страницы предупреждает о черновике. Экспорт при изменениях предлагает сохранить все черновики либо экспортировать последнюю сохранённую версию.

Конфликт revision открывает сравнение сохранённой версии и черновика.
Пользователь явно выбирает загрузку сохранённого текста или продолжение с
черновиком на новой revision. Второе не записывает данные автоматически:
требуется отдельное «Сохранить». Повторное изменение серверной версии во время
сравнения требует повторного выбора. При вводе во время отправки только
отправленный текст считается сохранённым; последующие символы остаются черновиком.

## Карта

Пустой курс содержит только корень с реальным названием. Карточки выводят название и описание, лекции — рамку. Перетаскивание фона перемещает область просмотра, колесо и кнопки меняют масштаб; «Вся карта» вписывает все объекты. Нажатие карточки или рамки открывает Note. Перемещение рамки переносит её карточки согласно сохранённой принадлежности; правый нижний угол меняет размер.

Ребро рисуется как polyline из центров и сохранённых относительных контрольных точек, с визуальным обрезанием у границ карточек для видимых стрелок. Нажатие линии открывает её свойства. Кнопка «Точка» и двойное нажатие линии добавляют точку; круглые ручки перетаскиваются; подпись и удаление доступны в инспекторе. Контрольные точки не меняют семантический тип связи.

Настройки сохраняют заливку, контур и форму карточек, цвет/толщину/штриховку/стрелки/подписи линий и скрытые типы Note. Скрытие не удаляет конспекты. Снятие карточки с карты и удаление Note — разные подписанные операции с разными подтверждениями. Возвращение Note на карту использует прежний ID Note. Список и поиск включают конспекты без карточек.

## Проверка и границы

Все авторские JS-модули проверяются `node --check` локальным Node из `.tools/node-v22.23.2-win-x64/`. Реальная браузерная интеграция и снимки выполняются интегратором в `tests/ui/` и `test-results/ui/`; окончательные результаты следует брать из общего отчёта, а не считать наличие элементов проверкой сценария.

Интерфейс рассчитан на десктопное рабочее пространство; на узком экране карта и редактор располагаются друг под другом, каталог переключается кнопкой в верхней панели. Разделитель на десктопе доступен мышью и стрелками клавиатуры, ширина сохраняется в браузере. Для ошибок есть inline-уведомления, сообщения формы, toast и независимый guard загрузки.
