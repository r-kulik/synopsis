# S05 — действия выделения, факты и источники

Статус: не начат. Входной gate: S03, команды домена S01/S02, результаты selection spike. Владелец: агент редактора/интеграции. Завершение визуального сценария требует S04.

## Комментарий пользователю

> Добавлю действия при выделении отформатированного текста: ссылку, создание конспекта и факт-комментарий. Результат будет записываться в Markdown; PDF-источники будут открываться отдельно от приложения.

## Scope и владение

Selection toolbar, поиск цели, local source patch, Fact UI, источники и source links. Карточка создаётся через общий API, а не прямой записью во внутренний state библиотеки карты. Изменения assets API выполняются с владельцем хранения.

Входы: [Markdown](../markdown-contract.md), [UX](../ux-flows.md), [модель](../domain-model.md), [приёмка](../acceptance.md), ADR D-03/D-12.

## Шаги

1. Подключить меню выделения только в режиме чтения и согласованную таблицу поддержанных диапазонов.
2. Добавить поиск существующих конспектов только в текущем курсе, включая объекты без карточек.
3. Реализовать revision-aware точечную вставку внутренней ссылки; не менять остальной Markdown.
4. Реализовать согласованное создание Note/Card/ссылки из выделения и показ новой карточки в свободном месте.
5. Добавить создание, скрытое отображение, раскрытие и редактирование Fact; список без привязки и повторное прикрепление.
6. Реализовать добавление PDF, прикрепление к лекции, ссылки на файл и страницу, открытие вне приложения.
7. Проверить невалидные цели, чужие факты, ошибки сохранения и отсутствие автоматических рёбер.

## Gate

- AC-09, AC-17–23, AC-26; AC-19/12 на реальной карте после S04.
- Ссылки на карточку не используются вместо ссылок на Note.
- Изменение маркера/подписи не теряет содержание факта; факт не появляется на карте.
- Ошибка второй части создания не оставляет необъяснимую полузапись.
- Внешнее открытие PDF и переход к странице проверены в принятом браузере; fallback описан.
- Сложные неподдержанные выделения не портят Markdown и не маскируются под успешную операцию.

Проверки: source patch fixtures, domain integration, браузерное выделение и открытие PDF. Выход: полный модуль ссылок/фактов/источников и отчёт S05. [Промпт](../prompts/S05-links-facts-sources.md).
