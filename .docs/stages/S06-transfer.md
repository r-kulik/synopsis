# S06 — переносимый курс .synopsis

Статус: не начат. Входной gate для начала: S01/S02. Владелец: агент хранения/переноса. Работа на fixtures допускается параллельно S03/S04; итоговая проверка использует реальные результаты S04/S05.

## Комментарий пользователю

> Реализую перенос курса одним файлом: конспекты, комментарии, карта, настройки, PDF и картинки. Проверю открытие в чистом хранилище и ошибки импорта без повреждения существующих курсов.

## Scope и владение

Transfer-модуль, архивный формат и его валидаторы, чтение assets через адаптер. UI экспорта/импорта согласуется с shell-владельцем. Не менять формат Markdown и карту без интегратора.

Входы: [архив](../synopsis-format.md), [модель](../domain-model.md), [приёмка](../acceptance.md), ADR D-04/D-05/D-13.

## Шаги

1. Реализовать снимок согласованной сохранённой revision курса.
2. Включить Markdown всех Note/Fact, метаданные, геометрию, стили/фильтры и байты вложений.
3. Валидировать внешние зависимости изображений; не выдавать отсутствующие файлы за самодостаточный экспорт.
4. Реализовать staging, проверки schemaVersion/путей/объёмов/ID и атомарную публикацию импортированного курса.
5. Реализовать принятую политику повторного импорта без неявной перезаписи.
6. Разделить допустимые невалидные текстовые ссылки и ошибки структуры архива.
7. Выполнить реальный export/import с данными editor/map/facts в отдельное хранилище.

## Gate

- AC-08 (перенос геометрии), AC-11 (настройки), AC-23, AC-28–30.
- Получатель видит и редактирует конспекты без исходных путей/сервера отправителя.
- Сохранены конспекты без карточек и факты без привязки.
- Ошибочный импорт не меняет существующий курс; неподдержанная версия не загружается молча.
- Сопоставление ID не связывает разные курсы.
- Контракт формата и сообщения ошибок соответствуют реализации; результаты проверены не только на моках.

Проверки: round trip по смыслу/байтам, повреждённые и adversarial ZIP fixtures, повторный импорт, недоступные картинки, реальные данные. Выход: transfer-модуль и отчёт S06. [Промпт](../prompts/S06-transfer.md).
