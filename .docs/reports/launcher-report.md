# Упрощённый запуск — 2026-09-14

## Изменения

- `Start Synopsis.cmd`: запуск на Windows двойным щелчком, поиск подходящего
  Python через `py`/`python`, понятное сообщение при отсутствии Python 3.11+.
- `python start.py`: тот же запуск из терминала. Старый модульный entry point
  сохранён. По умолчанию браузер открывается после ответа `/api/health`
  именно от запущенного экземпляра. `--no-browser` отключает это поведение.
- Повторный запуск на том же порту открывает только совпадающий экземпляр
  Synopsis с теми же данными и UI; другая библиотека/занятый порт даёт ошибку.
  Windows-сокет использует эксклюзивное владение портом.
- Данные по умолчанию — `.synopsis-data` рядом со `start.py`, не в случайном
  текущем каталоге терминала. Пользовательские курсы при проверках не менялись.
- `tools/build-release.py` собирает переносимый ZIP с готовым UI и лицензиями,
  без курсов и dev-зависимостей. Python 3.11+ нужен на машине получателя;
  pip, npm, venv и Docker для обычного запуска не нужны.
- README: описание, короткий старт, локальный SVG-логотип и значки технологий,
  скриншот настоящего UI, хранение данных и ограничения поставки.

## Проверки

Среда: Windows, Python 3.14.0, Chrome 152.0.7977.83.

- `python -m unittest discover -s tests`: 43/43.
- `python -m unittest map.tests.test_map`: 9/9.
- `npm run test:ui`: 3/3, включая новый сценарий автооткрытия и создание
  курса/конспекта через запрошенный браузеру URL.
- `npm run test:browser`: полный сценарий Chrome, включая сохранение,
  Markdown/формулы, связи, PDF, экспорт и импорт в чистую библиотеку.
- ZIP распакован в путь с пробелами и кириллицей. Приложение запущено из
  другого рабочего каталога через `python -S -B` (без site-packages).
  Проверены UI, каталог данных и повторный запуск через настоящий `.cmd`.
- SVG-логотип и значки отрендерены в Chrome и просмотрены визуально.

Автотест перехватывает запрос стандартного `webbrowser` через тестовый
обработчик, затем открывает полученный адрес в изолированном headless Chrome.
Личный браузер пользователя тесты не открывают; системная ассоциация браузера
на его компьютере отдельно не проверялась. При отказе обработчика сервер
продолжает работу и показывает адрес для ручного открытия.

## Границы

Это переносимая Python-поставка, не автономный `.exe` и не опубликованный
GitHub Release. macOS/Linux отдельно не проверены. Блокировка общего каталога
между серверами на разных портах не добавлялась: не запускайте их одновременно
с одним `--data-dir`. Эта проверка не закрывает прежний инцидент на личном
`localhost:8765` пользователя или независимую приёмку S08.
