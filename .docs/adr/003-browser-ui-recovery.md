# ADR-003 — рабочий браузерный UI после замечаний S08

Статус: реализовано; сценарии проверены в Chrome/Edge, независимый release gate
S08 не переобъявлен. Основание: пользователь потребовал полноценный красивый
интерфейс, отдельные HTML/JS/CSS и снял введённое исполнителями ограничение
«без библиотек». Исторические отчёты S00–S08 описывают прежнюю сборку.

## Решение

- Страницы `frontend/index.html` и `frontend/course.html` отдаются локальным
  сервером. Поведение разделено на ES-модули; оформление находится в CSS.
  `shell/page.py` больше не генерирует JavaScript внутри Python-строки.
- Браузерный Markdown разбирает remark с GFM и math. DOM создаётся по AST;
  HTML пользователя показывается текстом. Внутренние ссылки разрешаются
  только по snapshot текущего курса, чужой Fact не раскрывается.
- KaTeX отображает формулы с `trust: false` и локальной диагностикой ошибок.
  CodeMirror 6 редактирует каноническую строку Markdown. Библиотеки, CSS и
  шрифты собираются локально, без CDN в пользовательском запуске.
- `tools/markdown-entry.js` — исходник рендера/редактора; `npm run build`
  формирует поставляемый `frontend/markdown.js`. Точные версии находятся в
  `package-lock.json`, лицензии — в `frontend/vendor/LICENSES.txt` и bundle.
- Для карты используется ограниченный SVG-адаптер поверх существующего
  MapCommands: Pointer Events, перенос карточек/рамок, pan/zoom и ручные точки.
  Семантика и сериализация остаются в текущем домене; Pro-код не используется.
- Python HTTP/storage сохраняются, чтобы новый UI работал с уже созданными
  курсами. Замена сервера на TypeScript сама по себе не исправляет UI и
  потребовала бы миграции. Это уточняет предварительный stack baseline ADR-001.

## Выделение и сохранение

Состояние черновика хранится отдельно от сохранённого Note. Сервер требует
revision, сериализует команды одного процесса и публикует snapshot через
атомарную замену. Изменение карты не сбрасывает черновики.

Remark даёт позиции текстовых AST-узлов. Renderer строит карту UTF-16 границ
с учётом emoji, escapes и entities. Разрешено выделение внутри одного
текстового узла, включая текст внутри emphasis и ячеек таблиц. Ссылки, код,
формулы, HTML, task-list и переходы между узлами/блоками отклоняются. Сервер
повторно проверяет revision, UTF-16 границы, исходный текст и защищённые
контексты, затем применяет только raw patch. Полная пересериализация Markdown
не выполняется.

## Проверка

HTTP-тесты не являются доказательством работы UI. Добавлены отдельные
автоматические тесты в установленном Chrome/Edge с новым профилем, чистым
каталогом данных, перехватом ошибок JavaScript и снимками страниц.
Результаты конкретного прогона фиксируются в отчёте UI, без автоматического
принятия всего S08 по количеству unit tests.
