# Synopsis для Codex: навык + MCP

`synopsis-from-slides` отвечает за чтение презентаций, выделение сущностей и
качество объяснений. Локальный MCP-сервер `synopsis` отвечает за структурную
валидность, ID, связи, сохранение черновиков и экспорт `.synopsis`.

Обычный запуск приложения не изменился: `Start Synopsis.cmd`, без pip/npm.
Следующие зависимости нужны **только для MCP** и устанавливаются отдельно.

## Подключение на Windows

Из корня полной копии репозитория:

```powershell
python -m venv .venv-mcp
.\.venv-mcp\Scripts\python.exe -m pip install -r requirements-mcp.txt
```

Разово добавьте сервер (нужна доступная команда `codex`):

```powershell
$synopsisRoot = (Get-Location).Path
codex mcp add synopsis -- "$synopsisRoot\.venv-mcp\Scripts\python.exe" "$synopsisRoot\tools\run-mcp.py" --workspace "$synopsisRoot\.synopsis-mcp"
```

Эта команда добавляет локальное подключение в конфигурацию Codex. Если запись
`synopsis` уже есть, сначала посмотрите `codex mcp get synopsis`, не заменяйте
её вслепую. В IDE можно добавить STDIO-сервер через настройки MCP, указав те же
command/args. После подключения перезапустите расширение/откройте новую сессию.
См. [официальную инструкцию Codex](https://learn.chatgpt.com/docs/extend/mcp?surface=cli).

Навык лежит в `skills/synopsis-from-slides`. Скопируйте эту папку целиком в
`skills` внутри вашего `CODEX_HOME` (по умолчанию `C:\Users\ИМЯ\.codex\skills`).
Не перезаписывайте установленный одноимённый навык без проверки изменений.
Если репозиторий или окружение переместились, обновите command/args сервера.

## Использование

Прикрепите PPTX/PDF к новому диалогу и напишите:

```text
Используй $synopsis-from-slides. Сделай из этих презентаций курс
«Линейная алгебра»: разбей по лекциям, выдели понятия, примеры и задачи,
напиши конспекты со ссылками на слайды и свяжи понятия на карте.
Собери через Synopsis MCP файл для импорта.
```

Содержательные материалы агент читает доступными ему инструментами.
Сам MCP не содержит OCR/конвертера PPTX и не вызывает языковую модель/API.

Для вложения оригиналов/иллюстраций поместите нужные PDF/PNG/JPEG/WebP в
`.synopsis-mcp/inputs`. Альтернатива — добавьте к команде сервера
`--input-root "D:\Учёба\Материалы курса"`: доступ только к этому каталогу.
PPTX не является поддерживаемым источником Synopsis; перед вложением нужен PDF.
Без PDF ссылки на исходные слайды остаются текстовыми.

Результат будет в `.synopsis-mcp/exports`. На главной Synopsis нажмите
«Импортировать» и выберите полученный `.synopsis`. Основная `.synopsis-data`
не меняется при генерации. Черновики остаются в `.synopsis-mcp/drafts`.
Не открывайте эту черновую библиотеку для редактирования вторым HTTP-сервером,
пока MCP работает. Для визуальной проверки импортируйте экспорт в отдельную
тестовую библиотеку.

## Инструменты и границы гарантий

- `create_course`, `register_presentation`, `create_lecture`;
- `add_concept`, `add_example`, `add_task`, `add_fact`;
- `connect`, `update_note`, `attach_file`;
- `list_courses`, `get_course`, `get_note`, `validate_course`, `export_course`.

Сервер генерирует ID, раскладывает карточки по рамкам и проверяет каждую
мутацию до сохранения штатным структурным валидатором импорта. Некорректное
ребро, ссылка, владелец факта, диапазон слайдов или устаревшая revision приводят
к ошибке инструмента. Состояние курса при отказе проверки не меняется.
Перед выдачей архива выполняется настоящий обратный импорт в изоляции.

Это не доказательство правильности учебного содержания. Число исходных слайдов
в inventory и достоверность citations сообщает агент; число страниц вложенного
PDF вычисляет сервер. Наличие ссылки на диапазон не доказывает полноту пересказа.
За OCR, смысл, верность формул и понятность карты отвечает содержательная приёмка.
Это также не песочница для агента с отдельным произвольным shell-доступом:
навык запрещает обход MCP, но не отнимает у клиента его другие полномочия.

MCP использует STDIO через официальный SDK, без сетевого HTTP-порта. Доступны
только специально выделенные черновики; инструмента для правки основной
библиотеки или импорта в неё нет. Один процесс владеет workspace через OS-lock.
Лимиты архива сохранены: 1000 записей, 32 MiB на файл, 256 MiB до сжатия.
Геометрия автоматически пересчитывается при добавлении заметки; ручная раскладка
и удаление/смена типов заметок через MCP в этой версии не реализованы.

SDK `mcp==1.30.0` выбран из поддерживаемой ветки v1; переход на v2 потребует
отдельной проверки API. См. [официальный Python SDK](https://py.sdk.modelcontextprotocol.io/v1/).

## Проверки разработки

```powershell
python -m unittest tests.test_mcp_workspace
.\.venv-mcp\Scripts\python.exe -m unittest tests.test_mcp_transport
```

Первый набор не требует MCP-зависимостей. Второй использует официальный клиент:
инициализация STDIO, схемы инструментов, успешные/ошибочные команды, PDF,
экспорт и обратный импорт. Тесты не используют личные курсы.

Дополнительно, при установленном Chrome и dev-зависимостях UI:

```powershell
$env:SYNOPSIS_MCP_BROWSER_TEST = '1'
.\.venv-mcp\Scripts\python.exe -m unittest tests.test_mcp_transport
```

Проверка откроет именно импортированный MCP-архив в изолированном headless
Chrome: рамку, карточки, формулу, popover факта и список PDF. Скриншот:
`test-results/mcp/imported-course.png`.

Проверено 2026-09-14: 51 тест общего Python-набора в MCP-окружении и 9 тестов
карты прошли; настоящий STDIO-сценарий и браузерный сценарий выше прошли.
Навык прошёл `skill-creator/quick_validate.py` до установки и после неё.
Это техническая проверка на небольшом синтетическом курсе; реальных
презентаций для проверки качества конспектирования пользователь ещё не передал.
